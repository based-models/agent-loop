# based-models-agentloop

A provider-agnostic agent loop: transcript, provider seam, tool machinery, retry, tracing.
Import name: `agentloop`. **Private package** — never published to PyPI (the name
`agentloop` there belongs to an unrelated project). Install from git; see
[`docs/guides/installing.md`](docs/guides/installing.md) and
[`docs/guides/releasing.md`](docs/guides/releasing.md).

```bash
pip install "based-models-agentloop[anthropic] @ git+ssh://git@github.com/based-models/agent-loop.git@<commit-sha>"
```
